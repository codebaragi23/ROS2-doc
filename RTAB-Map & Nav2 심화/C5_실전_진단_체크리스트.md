# C5. 실전 진단 체크리스트

> RTAB-Map & Nav2 심화 시리즈 · Part C. Relocalization 심화
> 이전 문서: C4. Pose Jump 제어와 안정화
> 이 문서는 `rtabmap_nav_params_tuning_guide.md`(프로젝트 내부 자료)의 "5. localization jump" 항목을 이 시리즈 전체와 연결해 확장한 버전이다.

## 1. 개요

지금까지(A1~C4) 다룬 개념과 파라미터를 실제로 문제가 생겼을 때 어떤 순서로 확인할지 체크리스트로 정리한다. 이 문서는 새 개념보다는 **진단 순서 자체**가 핵심이다.

## 2. 핵심 개념: "Nav2 파라미터만으로는 근본 해결이 안 된다"

`rtabmap_nav_params_tuning_guide.md`는 이 점을 명확히 짚는다:

> "Nav2 쪽에서는 goal tolerance를 완화하거나 progress checker 시간을 늘려 증상을 줄일 수는 있지만, localization jump 자체의 원인은 RTAB-Map/odom/TF 쪽에서 찾아야 한다."

즉 Nav2 파라미터 튜닝(B4~B7)은 **증상 완화**이고, 근본 원인은 항상 이 시리즈의 Part A(지도 품질)와 Part C(RTAB-Map localization 자체)에 있다. 진단할 때 이 순서를 거꾸로 하지 않는 것이 중요하다.

## 3. 이 프로젝트에서의 진단 순서 (증상별)

### 증상: localization jump가 있을 때

1. `/odom`이 연속적인지 확인 (B2의 `odom→base_footprint` 계층 — EKF/휠 오도메트리 문제인지 먼저 배제)
2. `map → odom`이 갑자기 튀는지 확인 (B2의 `map→odom` 계층 — RTAB-Map localization 문제)
3. RTAB-Map localization confidence와 loop closure 로그 확인 (`/rtabmap/info`, C2~C3)
4. D435i RGB-D sync 상태 확인 (A2에서 다룬 `rgbd_sync` 안정성)
5. LiDAR scan과 camera_scan의 TF 정합 확인 (B3, B2)

### 증상: 목표 도착 판정이 안 될 때

1. 사용 중인 goal checker가 `general`인지 `precise`인지 확인 (B6)
2. RTAB-Map localization이 `map` 프레임에서 흔들리는지 확인 (C2~C4)
3. goal pose 주변 costmap에 장애물이 잘못 찍혀 있는지 확인 (B3)
4. `xy_goal_tolerance`/`yaw_goal_tolerance` 확인 (B6)
5. `progress_checker.movement_time_allowance` 확인 (B6)

### 증상: relocalization이 예상 시점에 발동하지 않을 때

1. C2의 5분류 중 어느 트리거에 해당하는지 먼저 분류
2. 해당 트리거를 감시하는 프로젝트 커스텀 로직이 실제로 살아 있는지 확인 (C2 5장 — 이 감시 로직 자체가 표준 기능이 아님을 기억)
3. C3의 관련 파라미터(`Vis/MinInliers`, `Rtabmap/LoopThr` 등)가 과도하게 엄격하지 않은지 확인

## 4. 테스트 시 기록하면 좋은 항목

튜닝/재현 실험마다 아래를 기록하면 원인 추적이 훨씬 쉬워진다 (`rtabmap_nav_params_tuning_guide.md` 원문 기준).

- 사용한 map과 RTAB-Map DB (어느 시점에 A1~A3로 만든 지도인지)
- 시작 pose와 goal pose
- 평균 속도와 총 이동 시간
- recovery 발생 횟수 (B6)
- planner/controller/progress checker 실패 여부
- `/odom` 연속성, `map → odom` jump 여부
- local/global costmap 스크린샷
- 장애물 근접 상황에서 `/scan`, `/camera_scan` 표시 상태

## 5. 빠른 판단표

| 증상 | 먼저 볼 영역 | 관련 문서 |
|---|---|---|
| 전역 경로가 안 나옴 | `allow_unknown`, global `robot_radius`/`inflation_radius`, map 품질 | B4, A3 |
| 좁은 통로에서 멈춤 | local inflation, `ObstaclesCritic`, `progress_checker` | B3, B5, B6 |
| 장애물에 너무 붙음 | local `robot_radius`, inflation, `repulsion_weight` | B3, B5 |
| 너무 느림 | `vx_max`, `wz_max`, `PathFollowCritic`, velocity smoother | B5, B7 |
| 움직임이 거침 | MPPI noise, accel/decel, velocity smoother | B5, B7 |
| 목표 도착 실패 | goal checker tolerance, localization, local costmap | B6, C2~C4 |
| 회전 중 위치가 튐 | `/odom`, EKF, RTAB-Map localization, TF | B2, C4 |
| unknown 영역으로 경로 생성 | `allow_unknown` | B4 |
